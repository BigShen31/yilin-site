# 个人作品集网站 PRD

## 1. 项目概述

### 1.1 项目名称
一林 - 个人作品集与品牌展示网站

### 1.2 项目目的
用于个人作品集展示及个人品牌建设，向潜在合作者、项目兴趣者及想了解过往经历的人提供一站式信息窗口。

### 1.3 目标受众
- 可能与一林合作的人
- 对一林项目感兴趣的人
- 想了解一林过往经历的人

---

## 2. 页面结构

采用**单页长滚动 + 锚点导航**模式，共 6 个板块：

### 2.1 导航栏（Navbar）
- **位置**：固定顶部
- **行为**：初始透明，滚动后切换为白底 + 轻微阴影
- **左侧**：站名 "一林"
- **右侧**：锚点导航链接（关于我 / 工作经历 / 技能 / 作品集 / 联系方式）+ 语言切换按钮（CN / EN）
- **移动端**：汉堡菜单，点击展开导航

### 2.2 Hero 首屏
- **核心内容**：姓名 "一林" + 一句话定位（中文："产品设计师 & 全栈开发者" / 英文："Product Designer & Full-Stack Developer"）
- **视觉**：白底 + 右侧浅蓝色渐变流体装饰元素
- **无头像**
- **动效**：文字渐入，装饰元素轻微浮动

### 2.3 关于我（About Me）
- **内容**：个人简介段落（中英各一套）
- **视觉**：大号板块标题 + 正文段落，左对齐，大量留白
- **动效**：滚动渐入（fade-up）

### 2.4 工作经历（Work Experience）
- **布局**：垂直时间线
- **每条记录包含**：公司名称、职位角色、起止时间、简述
- **视觉**：左侧蓝色线条 + 圆点，右侧圆角白色卡片（带轻微阴影）
- **数量**：初始 3 条占位，后续可扩展
- **动效**：滚动渐入，逐条依次出现

### 2.5 技能专长（Skills）
- **布局**：分组标签展示
- **标签样式**：圆角胶囊形，浅蓝底色（`#E8F4FD`）+ 深色文字
- **分组方式**：按类别分组（如"前端"、"后端"、"设计"、"工具"等），每组带小标题
- **视觉**：不使用进度条，避免模板化
- **动效**：滚动渐入

### 2.6 项目作品集（Projects）
- **布局**：2 列网格（移动端单列）
- **每个项目卡片包含**：
  - 封面图占位区域
  - 项目名称
  - 简短描述
  - 技术栈标签（小号胶囊标签）
  - 跳转链接（箭头图标）
- **数量**：3-5 个项目
- **视觉**：白色卡片 + 圆角 + 轻微阴影
- **交互**：hover 时卡片上浮 + 阴影加深
- **动效**：滚动渐入

### 2.7 联系方式（Contact）
- **内容**：邮箱 + 社交媒体图标链接（GitHub、LinkedIn、Twitter/X 等）
- **视觉**：图标化呈现，浅蓝 hover 效果
- **位置**：页面底部

## 3. 设计规范

### 3.1 整体气质
极简留白，略显高级。以内容为核心，让信息本身说话。

### 3.2 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FFFFFF` | 纯白底 |
| 浅蓝点缀背景 | `#E8F4FD` | 板块分隔、标签底色、装饰区域 |
| 强调色 | `#4A90D9` | 时间线、链接、按钮、hover 状态 |
| 主文字 | `#1A1A2E` | 深灰，接近纯黑但不刺眼 |
| 次要文字 | `#6B7280` | 描述文字、时间标注 |
| 边框/分割 | `#E5E7EB` | 卡片边框、分割线 |
| 卡片背景 | `#FFFFFF` | 白色卡片 + 轻微阴影 |

### 3.3 字体方案

| 用途 | 字体 | 回退 |
|------|------|------|
| 英文展示 | DM Sans | system-ui, sans-serif |
| 中文正文 | 系统默认 | -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif |
| 代码/标签 | JetBrains Mono | monospace |

### 3.4 排版节奏
- 板块间距：`py-24` ~ `py-32`（6rem ~ 8rem）
- 内容最大宽度：`max-w-4xl`（56rem / 896px）
- 板块标题字号：`text-3xl` ~ `text-4xl`，加粗
- 正文行高：`leading-relaxed`（1.625）
- 正文字号：`text-base`（1rem）

### 3.5 动效规范

| 场景 | 动效 | 参数 |
|------|------|------|
| 板块进入视口 | fade-up 渐入 | translateY(20px→0), opacity(0→1), duration 600ms, ease-out |
| 工作经历逐条 | 依次渐入 | 每条间隔 100ms |
| 项目卡片 hover | 上浮 + 阴影加深 | translateY(-4px), shadow 增大, duration 200ms |
| 导航栏滚动 | 透明→白底 | 背景色过渡, duration 300ms |
| 语言切换 | 内容淡入淡出 | opacity 过渡, duration 200ms |

### 3.6 设计禁忌
- 不使用进度条展示技能（过于模板化）
- 不使用头像/照片
- 不使用紫色渐变
- 不使用过度装饰性图标或插画
- 不使用自动轮播
- 不使用全屏深色背景（保持白底极简）

## 4. 技术方案

### 4.1 技术栈

| 维度 | 选型 | 版本 |
|------|------|------|
| 框架 | Next.js (App Router) | 16 |
| 语言 | TypeScript | 5 |
| UI 组件 | shadcn/ui (Radix UI) | 最新 |
| 样式 | Tailwind CSS | 4 |
| 国际化 | 轻量客户端 i18n（JSON 语言包 + React Context） | 自建 |
| 动效 | CSS 动画 + Intersection Observer | 原生 |

### 4.2 国际化方案
- 使用 JSON 语言包存储中英文本（`/locales/zh.json`、`/locales/en.json`）
- 通过 React Context + Provider 管理当前语言
- 语言切换按钮位于导航栏右侧，切换后内容即时更新（无页面刷新）
- URL 不随语言切换变化
- 默认语言：中文

### 4.3 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| 移动端 | < 768px | 单列布局，汉堡菜单，项目卡片单列 |
| 平板 | 768px ~ 1024px | 单列布局，导航展开，项目卡片 2 列 |
| 桌面端 | > 1024px | 居中布局，项目卡片 2 列，内容 `max-w-4xl` |

### 4.4 项目结构（规划）

```
src/
├── app/
│   ├── layout.tsx          # 根布局（字体、元信息）
│   ├── page.tsx            # 首页（组装所有板块）
│   └── globals.css         # 全局样式
├── components/
│   ├── ui/                 # shadcn/ui 组件
│   ├── navbar.tsx          # 导航栏
│   ├── hero.tsx            # Hero 首屏
│   ├── about.tsx           # 关于我
│   ├── experience.tsx      # 工作经历
│   ├── skills.tsx          # 技能专长
│   ├── projects.tsx        # 项目作品集
│   ├── contact.tsx         # 联系方式
│   └── language-switcher.tsx # 语言切换
├── i18n/
│   ├── provider.tsx        # 国际化 Context Provider
│   ├── zh.json             # 中文语言包
│   └── en.json             # 英文语言包
└── lib/
    └── utils.ts            # 工具函数
```

### 4.5 部署形态
- **第一版**：静态导出（`next export`），无需后端
- **后续扩展**：预留 API Routes 能力，可无缝接入后端（联系表单、博客 CMS 等）
